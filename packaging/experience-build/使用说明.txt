 iOS 体验版 —— 中文界面 / 长时间稳定 / 无日志
 打包日期：2026-11-19
============================================================

【这一版和之前的区别】
  1. 中文界面完全正常：系统卷补回了全部 zh_CN / zh_HK / zh_TW 本地化目录，
     并且换上了 Apple 原始的完整 PingFang 字体（36 个字面，77.8MB）。
     设置、图标名、Safari 都是中文，不再有方块。
  2. 没有定时器：去掉了 cmdline 里的 loader_return_after=1800
     （它就是"用着用着 30 分钟自动黑屏停住"的根因）。
     只要你不主动关机/重启，想用多久就多久。
  3. 没有日志：去掉了 -v，内核不再把文本日志画到屏幕上
     （原来那个文本控制台会滚动、拖慢启动，也不好看）。
  4. 开机后不连电脑、不装任何演示 App，纯系统。

【包里有什么】
  刷机-体验版.bat   —— 双击它（唯一需要你操作的东西）
  runtime\          —— 内置 Python（不用你电脑装 Python）
  site-packages\    —— 内置 pyusb（USB 通信库）
  libusb-1.0.dll    —— 内置 USB 库
  loader-logfix.img —— 引导程序（xnuloader）
  system.apfs       —— iOS 系统镜像 2.73GB（中文 + 完整字体 + modem 固件）
  itn-exp.bin       —— 体验版内核 + ramdisk + 启动参数
  precheck.py       —— 刷机前自检（不通过就不碰手机）
  devcheck.py       —— 检查手机是否已进 fastboot / 驱动是否可用
  driver_winusb.ps1 —— 可选：尝试给手机装标准 WinUSB 驱动
  fb_libusb.py      —— 纯 Windows 刷机程序（不需要 fastboot.exe）
  versions.json     —— 版本清单

【怎么刷】
  1. 手机：长按电源关机 → 按住「音量下 + 电源」直到出现 fastboot 画面
  2. 数据线连电脑（尽量用主板后置 USB 口）
  3. 双击「刷机-体验版.bat」→ UAC 点「是」
  4. 看黑窗口里的进度，约 2 分钟出现 FLASH DONE
  5. 手机 1~2 分钟后进入 iOS 桌面（首次启动稍慢，系统镜像在内存里）

【关于驱动（重点）】
  脚本会先检查手机能不能被 libusb 打开：
    - 能打开 → 直接刷，什么都不用装
    - Windows 看得到手机、但 libusb 打不开 → 说明 USB 驱动不对
      这时脚本会【提示】问你要不要试装微软 WinUSB 驱动：
        · 直接按回车 = 跳过，继续往下走（脚本不会拦你）
        · 输入 y 再回车 = 让它尝试装（可能需要几秒）
      如果装完还是不行，用 Zadig 手动指定：
        Options → List All Devices → 选 18d1 那个设备 → WinUSB → Replace Driver
    - 完全找不到手机 → 说明还没进 fastboot，不是驱动问题
  也就是说：驱动只是【提示】，装不装、跳不跳过，你按回车都能继续。

【刷完之后】
  - 想关机：长按电源键（和在真 iPhone 上一样）
  - 这一版没有任何到点自动停机的逻辑，插着电可以一直放着
  - /private/var 是内存盘（hk_data=2）：
      · 每次重启，Wi-Fi 密码会丢，需要在 设置 → Wi-Fi 里重新连一次
      · 每次重启，自己装的第三方 App 会丢（系统 App 都在）

【已知限制（不是这一版的问题，是移植进度）】
  - 相机：还不能用（Camera App 打不开预览）
  - App Store / 正常安装 ipa：还没做（有自己的一套安装链路，未内置到本版）
  - 睡眠/唤醒：没有完整实现，长时间放着屏幕常亮更稳
  - 蓝牙/Wi-Fi/基带（数据+通话）都可用，但偶发需要重连

【出问题怎么办】
  - 刷机中途失败：不要拔线，把黑窗口全部输出截图发出来，可重复运行脚本
  - 开机黑屏 / 白苹果：重新进 fastboot 再刷一次（脚本可重复执行）
  - 刷完卡在 fastboot：长按电源关机后重新进 fastboot，再运行一次脚本

【原理一句话】
  xnuloader 是一个 UEFI 小引导器，把内核 + ramdisk 从 USB 收进内存后跳到 XNU；
  系统卷（APFS，含中文）也在内存里被挂起来当根文件系统。
  所以"刷机"其实每次都是把 2.7GB 塞进手机内存，断电即失，这也是为什么
  每次都要重新刷、为什么 /var 的东西不保留。
